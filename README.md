# 🌾 Agro-Marketplace Platform

A modern, mobile-responsive decentralized marketplace designed to bridge the gap between local farmers and wholesale agri-buyers. This platform empowers agricultural producers to list harvests in real-time, eliminating predatory middlemen and streamlining food supply logistics.

## 🚀 Core Features
*   **Dynamic Harvest Feed:** Real-time visibility into available crops, grain volumes, pricing per kg, and farmer locations.
*   **Farmer Upload Dashboard:** An interactive portal allowing local farmers to instantly upload and showcase new yields directly from their mobile devices.
*   **Smart Query Filters:** Instant search and category segregation (e.g., Grains, Tubers, Vegetables) for industrial buyers.
*   **Instant Communication:** Direct transactional channel routing between wholesale buyers and growers (Powered by automated WhatsApp API hooks).

## 🛠️ Tech Stack & Infrastructure
*   **Frontend UI:** Vanilla JavaScript, HTML5, semantic structure.
*   **Styling Engine:** Tailwind CSS via CDN injection for optimized mobile responsive layouts.
*   **Cloud Cloud Deployment Pipeline:** Automatically integrated through GitHub triggers into **Vercel Edge Networks** for low-latency worldwide availability.
